# Agent assets

This directory contains instructions and reusable assets for coding agents.

- `AGENTS.md` at the repository root is the authoritative instruction source.
- Reusable skills, prompts, and role definitions live under this directory.
- Claude Code enters through the root `CLAUDE.md` and keeps tool-specific runtime settings under `.claude/`.
- A `workflows/` directory, when present, contains former GitHub Actions definitions retained for reference; files here do not run automatically.
