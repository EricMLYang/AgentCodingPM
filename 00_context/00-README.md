# 00_context — Agent Coding PM 的權威知識基底

## 這是什麼

`00_context/` 是 **AgentCodingPM 的長期知識庫**。當 Agent 進入這個 Repo 工作時，會把這個資料夾載入為 context，所以這裡的每一份檔案都應該：

- **結論先行**（TL;DR 放在最前面）
- **可被掃讀**（Agent 與人類都能在 30 秒內找到要的東西）
- **單一主題**（一個檔案一個主題，不混搭）
- **長期穩定**（每季 review 一次，過期內容搬 `02_精選文章/`）

## 三層分工

```
01_inbox/      ← 短期信號池（< 5KB / 月清空）
00_context/    ← 長期權威知識（這裡）
02_精選文章/    ← 經篩選的外部觀察與深度研究（只讀，有上限要篩選）
```

每份 context 檔的 `sources:` frontmatter 會指回 `02_精選文章/` 的原檔（如果該原檔有保留）；若原稿已被完全萃取且無外部引用價值，則直接刪除並在 sources 註明「原稿已合併刪除」。

## 編輯規範

### 新增主題

1. 確認新主題不能合進現有 09 個檔（不要為了一個小節再開檔）
2. 命名：`<兩位數字>-<主題中文>.md`
3. Frontmatter 必填 `title / status / last_review / sources / tldr`
4. 在這份 README 的「閱讀順序」與「主題分類速查」加一行

### 修改既有主題

1. 改完更新 `last_review` 日期
2. 重大修改在檔案末尾加「## 變更日誌」一行
3. 如果是「推翻原本結論」，archive 舊版本：複製檔案到 `02_精選文章/<原檔名>_v<日期>.md` 再覆寫

### 刪除主題

1. **不要直接刪**。先把檔案搬 `02_精選文章/` 並加 deprecation 說明
2. 在這份 README 把該檔從清單拿掉
3. 在替代檔的 `sources:` 列出被棄用檔案
